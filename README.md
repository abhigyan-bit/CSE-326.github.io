# LocalVibe – Local Market Online Store for Small Vendors

A simple first-year frontend project made with **HTML and CSS only**. No JavaScript is used.

## Pages
- `index.html` – Customer home page
- `shop.html` – Product listing
- `product.html` – Product details
- `cart.html` – Shopping cart
- `tracking.html` – Sample order tracking
- `register.html` – Customer login and registration forms
- `vendor-dashboard.html` – Vendor dashboard and add-product form
- `admin-dashboard.html` – Admin dashboard
- `style.css` – Common website styling

## Project note
This is a frontend demonstration. Login, cart calculations, payment, order tracking, and saving products are not connected to a database or backend. Product images load from Unsplash and require an internet connection.
